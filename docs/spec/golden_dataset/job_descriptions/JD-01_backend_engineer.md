# Lowongan: Backend Engineer (Mid–Senior)

**Perusahaan:** PT Nusantara Digital Sejahtera (fiktif)
**Lokasi:** Jakarta (hybrid)
**Tipe:** Full-time

## Tentang posisi

Kami mencari Backend Engineer untuk membangun dan mengelola layanan API
platform pembayaran dan logistik kami yang melayani ratusan ribu pengguna.

## Tanggung jawab

- Merancang, membangun, dan memelihara REST API dan microservices di production.
- Mendesain skema database dan mengoptimalkan query.
- Men-deploy layanan dengan container ke lingkungan cloud.
- Melakukan code review dan membimbing engineer junior.

## Kualifikasi wajib

- Minimal 3 tahun pengalaman sebagai Backend Engineer / Backend Developer.
- Menguasai Python (FastAPI, Django, atau Flask).
- Berpengalaman dengan PostgreSQL.

## Kualifikasi yang diutamakan

- Pengalaman membangun REST API atau microservices yang berjalan di production.
- Terbiasa menggunakan Docker.
- S1 Teknik Informatika, Ilmu Komputer, Sistem Informasi, atau bidang terkait.

## Nilai tambah

- Pengalaman dengan Kubernetes atau cloud (AWS, GCP, Azure).
- Memiliki sertifikasi cloud (AWS, Google Cloud, atau Azure).
- Memiliki pencapaian terukur di bidang backend (performa, skala, efisiensi).
- Pengalaman memimpin atau membimbing tim teknis.
